## Codebase Patterns
- Prisma 7 no longer accepts `url` in schema.prisma datasource; move it to `prisma.config.ts` `datasource.url`
- Prisma 7 no longer accepts `datasourceUrl` in PrismaClient constructor; just use `new PrismaClient()`
- Prisma config file is `prisma.config.ts` (not just schema); db URL set there as `file:./prisma/dev.db`
- `node_modules/.bin/tsc` may be a copy (not symlink) breaking execution; fix with `ln -s ../typescript/bin/tsc node_modules/.bin/tsc`
- When scaffolding with create-next-app in a temp dir and copying files, use `cp -r /tmp/pkg/.` NOT with `--preserve` to avoid copying broken symlinks, then do `npm install` fresh to regenerate node_modules
- The copied .git directory from create-next-app initializes on `main`; create `ralph/phase-1-foundation` branch afterwards
